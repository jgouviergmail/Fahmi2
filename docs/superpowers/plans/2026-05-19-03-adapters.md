# Plan 03 — Adapters externes Implementation Plan

> **For agentic workers:** Execution inline (no subagents). Steps use checkbox (`- [ ]`) syntax.

**Goal:** Implémenter les adaptateurs externes (FFmpeg, STT FasterWhisper + OpenAI, LLM DeepSeek), leurs interfaces communes, leurs fakes pour les tests des couches supérieures, et l'implémentation concrète TF-IDF du `GlossaryRetriever`.

**Architecture:** Chaque adapter externe implémente un `Protocol` défini dans `_interface.py` du sous-package. Les fakes (`FakeSTTProvider`, `FakeLLMProvider`) implémentent les mêmes Protocols pour les tests cross-couche.

**Tech Stack:** `ffmpeg-python` (wrapper), `faster-whisper`, `openai` SDK (compatible DeepSeek), `scikit-learn` (TF-IDF), `tenacity` / `with_retry`.

**Référence spec :** sections 6.1 (STTProvider), 6.2 (LLMProvider), 6.3 (FFmpeg, MarkdownRenderer reporté), 5.5 (retrieval).

## Tasks (résumé)

1. **STT interface + Transcription + Segment** : Protocol, dataclasses immuables
2. **FakeSTTProvider** : impl scénarisable
3. **FFmpegExtractor** : extraction audio MP4 → WAV 16kHz mono via subprocess
4. **FasterWhisperAdapter** : appel local (CUDA requis), skip si non-Windows ou pas CUDA
5. **OpenAIWhisperAdapter** : appel HTTP, testé avec `responses`
6. **LLM interface + Message + LLMResponse** : Protocol, dataclasses
7. **FakeLLMProvider** : scénarisable
8. **DeepSeek pricing constants** : tarifs v4-flash et v4-pro
9. **DeepSeekAdapter** : SDK OpenAI compatible, testé avec `responses`
10. **TfidfGlossaryRetriever** : scikit-learn, top-K par cosine similarity

Chaque task suit : tests failing → impl → verify (pytest/ruff/mypy) → commit.
